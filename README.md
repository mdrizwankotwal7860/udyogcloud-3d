# UDYOGCLOUD – Complete Realistic 3D Cloud Infrastructure Campus

> **Tagline:** Affordable Cloud Infrastructure for Small Industries  
> **Built for:** Small manufacturing, textile, food processing, printing, furniture, and wholesale businesses across India.

---

## 🌟 Overview

**UDYOGCLOUD** is an interactive, browser-based, full-scale 3D industrial technology campus model created using **Three.js** and WebGL. It visualizes the entire UdyogCloud managed cloud platform, illustrating why small industries need affordable, professionally managed cloud infrastructure without the complexity or high capital costs of global hyperscalers or fragile on-premise hardware.

---

## 🏛️ Campus Architecture & 3D Environments

The connected 3D campus contains:
1. **Central UdyogCloud Enterprise Data Center (Hero Facility)**
   - Metallic architectural facade with glass curtain walls and glowing blue LED crown strips.
   - 4 rows of full-height enterprise server racks (28 racks total) on raised anti-static flooring.
   - N+1 redundant power vault: 3 UPS battery modules + heavy industrial standby diesel generator with exhaust stack.
   - 4 CRAC precision cooling air conditioners with active ventilation ducts.
   - 100G fiber-optic core backbone routing wall with status port activity indicators.
   - 8 Service Zone markers: Cloud Storage, Database Clusters, Compute Nodes, Application Hosting, Automated Backups, Docker Containers, KVM Virtualization, and Hardened Linux Kernels.
   - 24/7 Security vestibule with biometric scanner, CCTV monitoring, and NOC workstation.

2. **Six Small-Scale Industry Customer Plants**
   - **Industry 1: Automobile Manufacturing** – CNC machines, conveyor assembly line with rollers, inventory shelves, forklift, workers, and CAD workstations.
   - **Industry 2: Textile & Garment** – Sewing machines, fabric rolls, cutting tables, designer workstations, and inventory racks.
   - **Industry 3: Food Processing & Sweets** – Commercial mixers, stainless steel processing counters, packaging lines, cold storage unit, and QC lab.
   - **Industry 4: Printing & Packaging** – Industrial offset printing presses, label printers, dual-monitor graphic design workstations, and paper pallet storage.
   - **Industry 5: Furniture & Woodworking** – Wood cutting and shaping machines, assembly workbenches, lumber storage, cabinet pieces, and design computers.
   - **Industry 6: Wholesale & Distribution** – Multi-tier warehouse storage racks, barcode scanning desks, dispatch area, loading dock with ramp, and logistics computers.

3. **Cloud Operations & NOC Command Center**
   - Tiered command consoles with multi-monitor workstations.
   - Mega curved NOC status wall tracking global infrastructure health.
   - Dedicated consultation suite showing a cloud architect configuring infrastructure for a small factory owner.
   - Core message: *"Small industries do not need to build their own cloud management team. UdyogCloud provides professional setup, management, and support."*

4. **Customer Experience & Onboarding Office**
   - Interactive walk-through of the 7-Step Customer Journey (Registration → Resource Selection → Pro Configuration → Data Migration → App Access → Telemetry Monitoring → Transparent Billing).

5. **Competitive Positioning Plaza (AWS, Azure & UdyogCloud)**
   - Outdoor architectural comparison exhibit detailing why hyperscalers are built for large enterprises while UdyogCloud specializes in making right-sized, zero-DevOps cloud accessible to MSMEs.

6. **Campus-Wide Fiber Network & Real-Time Data Streams**
   - 3D fiber-optic spline conduits linking all 6 industry plants to the central data center router core.
   - Bidirectional animated glowing data packets (uplink and downlink) flowing along curves.
   - 22m microwave telemetry communication mast atop the data center with pulsating aviation beacon.

## 🚀 How to Run Locally

Because the project uses standard ES Modules (`import`/`export`) and an import map, it needs to be served via any local HTTP server:

### Option 1: Python (Built-in)
```bash
# Navigate to the project directory
cd e:\cloud_3D_Model

# Start local server (Python 3)
python -m http.server 8080
```
Open your browser at `http://localhost:8080`

### Option 2: Node.js (npx serve)
```bash
npx serve . -p 8080
```
Open your browser at `http://localhost:8080`

### Option 3: VS Code / IDE Live Server
Right-click `index.html` and choose **"Open with Live Server"**.

## 🎬 8-Scene Presentation Mode

The bottom navigation bar allows judges and spectators to step through the structured presentation journey or press the **Play (▶)** button for an automated cinematic tour:
- **Scene 1 – Introduction**: High-altitude cinematic aerial establishing view of the complete campus.
- **Scene 2 – Industries & Their Problems**: Camera glides over the 6 industrial plants, explaining on-premise IT pain points.
- **Scene 3 – Customer Registration**: Zoom into the Customer Experience Center showing frictionless signup.
- **Scene 4 – Cloud Service Selection**: Highlights right-sized storage, database, and compute packages.
- **Scene 5 – Inside the Data Center**: Camera enters the server room, showcasing racks, Linux, KVM, and Docker.
- **Scene 6 – Connectivity & Data Streams**: Elevated angle showing bidirectional glowing fiber data packets pulsing across campus.
- **Scene 7 – Operations & Billing**: Inside the NOC command room showing managed support and resource monitoring.
- **Scene 8 – Complete Ecosystem**: Seamless camera retreat back to the original panoramic aerial view.

## 🛠️ Interactive Features & Keyboard Shortcuts
- **Orbit & Free Navigation**: Left-click + drag to rotate, right-click + drag to pan, scroll to zoom in/out.
- **Presentation Hotkeys:**
  - **`F` / `⛶ Fullscreen`**: Toggle full-screen exhibition presentation mode.
  - **`R` / `🏛️ Hide Roofs (Cutaway)`**: Toggle factory roofs between exterior sawtooth architecture and unobstructed interior shop-floor cutaway view.
  - **`S` / `⚡ Trigger Data Surge`**: Fire high-speed (2.6x) data replication burst along campus fiber conduits.
  - **`Spacebar` / `▶ Play`**: Auto-play or pause cinematic presentation tour.
- **Physical Architectural Diorama**: Walk-around 3D comparison exhibit in the Western Courtyard comparing traditional in-house server room hazards against UdyogCloud enterprise micro-pods.
- **Exploded 3D Software Architecture Stack**: Multi-tier 3D floating layered architecture inside the Data Center showing Bare-Metal → Linux Kernel → KVM Virtualization → Docker Containers → Customer MSME Applications.
- **Live NOC Telemetry Wall**: High-resolution dynamic canvas displays inside Operations Center tracking simulated tenant workloads and campus network throughput in real time.
- **Usage-Based Billing Calculator**: Click `💰 Pricing Calculator` in the top-right toolbar to dynamically scale vCPU, RAM, storage, and databases to calculate real-time monthly billing.
- **8 Problems Solved Modal**: Click `⚠️ Problems Solved` to review the side-by-side comparison between traditional IT headaches and UdyogCloud solutions.
- **Hyperscaler Comparison**: Click `⚖️ AWS / Azure Comparison` to inspect the differentiation table.
